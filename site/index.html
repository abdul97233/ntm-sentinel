Five engines

Everything about a website, in one place

Click the toolbar icon on any site and NTM Sentinel analyses it right inside your browser.

ScamLens

Explainable security and phishing indicators.

  • IP, punycode and look-alike (homograph) domains
  • Brand impersonation and typosquats
  • Risky password forms, mixed content, missing security headers
  • Every finding shows evidence, an explanation and advice

PrivacyGuard

See who a page talks to, with passive observation only.

  • Third-party domains and request counts
  • ~90 known analytics, ad, session-replay and fingerprinting services
  • Cookie security attributes (never values)
  • Optional fingerprinting-API indicators

StackPeek

Detect the technologies behind any site.

  • ~80 signatures: React, Next.js, Vue, WordPress, Shopify…
  • Libraries, analytics, CDNs, hosting and servers
  • Versions where visible, with confidence levels
  • Shows the exact evidence for each detection

DevLens

A design and DOM inspector for developers.

  • Element picker, box model and computed CSS
  • Color palette in HEX / RGB / HSL, plus typography
  • Image and font asset explorer
  • Export design tokens and CSS variables

APIWatch

A network and API inspector inside DevTools (F12 → NTM APIWatch): filter requests, browse JSON responses in a searchable tree, and export as cURL, JSON or a Postman collection. Authorization headers, cookies and tokens are redacted by default.

Privacy by design

Your browsing stays on your device

NTM Sentinel reads a page only after you allow it, and analyses it locally.

No site access at installA page is read only after you click the icon or grant that site.
Local analysisAll five engines run inside your browser.
No telemetryNo analytics, no ads, no tracking of users.
Values never readCookie and storage values are never shown, stored or uploaded.
Optional permissionsCookies, redirect tracking and all-sites access are opt-in.
One-click deleteRemove all local data any time from Settings.
