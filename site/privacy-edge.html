NTM Sentinel – Privacy Policy

Effective date: November 18, 2026
Product: NTM Sentinel v0.1.0
Publisher: NTM Sentinel

1. Introduction

NTM Sentinel is a browser security and website diagnostics extension for Microsoft Edge. It helps users inspect suspicious websites, website technologies, privacy indicators, webpage structure, and network activity.

We designed NTM Sentinel with a local-first approach. This policy explains what information the extension accesses, how it is processed, and how users maintain control over it.

2. Information the extension accesses

Depending on which features users activate, NTM Sentinel may access:

  • Website URLs and redirect information for security analysis.
  • Webpage content and DOM elements for inspection.
  • CSS properties, fonts, colors, and website assets.
  • Third-party resource and tracker information.
  • Cookie and browser storage metadata.
  • Network request and response information, including headers, status codes, timing, and response content when inspected through APIWatch.
  • Website technology indicators.

Network requests and webpage content can contain personal or authentication information. Users should avoid sharing sensitive request or response information.

3. How information is processed

The v0.1.0 extension performs its core analysis locally in the browser.

The extension uses browser extension storage to maintain settings and preferences. Website analysis and inspection information is processed within the browser as required by the selected feature.

APIWatch can inspect network request and response information through browser developer tools. Response content is inspected when the user requests it in the interface.

4. Data transmission and third parties

The v0.1.0 package is configured for local-only operation and does not have an NTM cloud backend configured.

We do not sell user data or use it for advertising or profiling.

The extension does not intentionally transmit browsing activity, webpage content, cookies, authentication information, or API response bodies to NTM servers in this release.

Websites and online services that users visit may independently receive information through normal browser requests. Their data practices are governed by their own privacy policies.

If future versions introduce cloud-based services or third-party integrations that process user information, this policy and the extension's disclosures will be updated before those features are enabled.

5. Data retention and deletion

Extension settings are stored using browser extension storage.

Users can clear locally stored extension data through Microsoft Edge's extension settings or remove the extension.

NTM Sentinel does not operate a cloud account or user-data database in v0.1.0.

6. Security

We aim to minimize data access and process information locally wherever possible. Users should not export or share network captures, request headers, or response bodies containing passwords, access tokens, personal information, or other confidential data.

7. Children's privacy

NTM Sentinel is a general-purpose browser security and developer utility. It is not designed to collect personal information from children.

8. Changes to this policy

This policy may be updated when functionality, data processing, or integrations change. The latest version will be published at the official privacy policy URL.
